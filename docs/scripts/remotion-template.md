## The scene-authoring contract

`Scenes.tsx` is where per-video work goes (the equivalent of rewriting scene functions in
`compose.html`). A scene component:

- takes `t` (seconds) as a prop
- reads its word timings from `W(i)` (`caps.json` sentence `i`)
- returns `null` outside its time range
- uses `T.*` for every colour (never a literal)
- is a visual metaphor for what's said at that moment, not decoration

`VideoOverlay` renders over the video itself (inside the card) — e.g. a glitch.
`Scenes` renders over everything — cards, counters, panels.

## Gotchas

- The rect presets here have **drifted** from `compose.reference.html` — see the drift
  table in [../engines.md](../engines.md#drift).
- `Ad.tsx` hardcodes the video `objectPosition: '50% 26%'`; the light engine uses
  `faceAnchor` from `theme.json`. Unifying this is a [design](../design/) task.
- After editing `Scenes.tsx`, run `safe_check.js` (the pixel check needs `compose.html`,
  but the hook check still runs; or set `guides:true` and eyeball the studio).
